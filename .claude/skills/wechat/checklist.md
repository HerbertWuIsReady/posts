# 微信发布前核对清单

## 必须手动做的
- [ ] **图片逐个上传素材库** —— HTML 里是灰框占位,微信不认本地路径。上传后在编辑器里替换
- [ ] **封面图** —— 比例见后台要求,单独上传
- [ ] **标题 / 摘要** —— 从 front matter 的 `wechat.title` / `wechat.digest` 复制进后台
- [ ] **原创声明** —— 按需勾选

## 粘贴流程
1. 浏览器打开 `content/<slug>/out/wechat.html`
2. 全选(Cmd/Ctrl+A)→ 复制
3. 粘进微信编辑器正文区
4. **不要**直接粘 HTML 源码,微信不解析

## 粘完后检查
- [ ] 标题层级是否还在(微信有时吃掉 margin)
- [ ] 引用框的背景色和左边线是否保留
- [ ] 代码块没串行、没丢缩进
- [ ] 表格在手机预览下没横向溢出
- [ ] 文末参考链接列表在(正文里的外链已被收到这里)
- [ ] 公式显示正常(复杂公式应已转图片)

## 手机预览
- [ ] 用"预览"发到自己微信上真机看一遍
- [ ] 段落没有出现孤字成行
- [ ] 一级标题上方留白明显大于下方
